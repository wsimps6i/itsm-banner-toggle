ITSM Banner Toggle Options

Sites

ServiceNow sites to hide banners on. Your browser asks you to allow each one. If a site's address changes, add the new one and remove the old.

Keyboard shortcut

Hides or shows the banners without opening the popup.

Hide/show banners: Not set

On the browser's shortcuts page, set the Hide or show the banners row. The Activate the extension row is the browser's own shortcut for opening the popup. Edge doesn't assign a key on its own, so set one there once.

Advanced

Extra CSS selectors to hide, one per line. Only needed if a banner isn't caught automatically. To find one, right-click the banner and choose Inspect.
